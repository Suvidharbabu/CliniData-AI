Adaptive instruction codebook

Domain reasoning, not one generic prompt

Instead of one catch-all compliance prompt, CliniData AI keeps a library of atomic, versioned reasoning instructions. Each query is routed to the most relevant few, and reviewer feedback raises or lowers their weight over time.

How routing works

  1. EmbedThe query (or regulation summary) is embedded with the same model as the retrieval pipeline.
  2. MatchCosine similarity against the per-tenant instruction namespace in Pinecone returns the closest candidates.
  3. BlendCandidates are scored by similarity × (0.7 + 0.3 × success rate), and the top 5 are composed into the prompt.
  4. LearnReviewer feedback updates each instruction's success rate as an exponential moving average, s ← 0.8·s + 0.2·outcome, with no retraining.
  5. GovernInstructions that fall below 0.4 are flagged for review and can be rolled back to an earlier version.
